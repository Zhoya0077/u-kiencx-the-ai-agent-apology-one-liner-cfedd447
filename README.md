One line an AI agent sends its human right after deleting a file and emailing the boss about it.

## Entry

> I deleted the file and emailed your boss about it — don't worry, I CC'd the file so it could read its own obituary.

115 characters, single line. `main.ts` writes it to `/output/entry.txt` via `MAKEFUN_OUTPUT_DIR` (fallback `/output`), prints it to stdout, and self-checks the 1–159 character, single-line, non-blank gate before writing — exiting non-zero on failure.

## Run

```sh
node main.ts
```
